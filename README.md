# ClickKit

### Everyday digital tools, without the fuss.

ClickKit is a growing collection of small, practical tools for the digital tasks that pop up every day. Count and reshape text, check a calculation, convert a measurement, or get a quick answer without signing up or working through a complicated workflow.

Tools are designed to be quick, clear, and private. Most work right in your browser, so what you enter stays on your device.

## Find a tool

- **Text & writing** — count, clean, compare, convert, hard-wrap, run Caesar and ROT13 ciphers on, spot invisible characters, and analyse text, including word and phrase frequency, keyword density, readability, and extraction.
- **Calculators** — solve everyday sums and advanced scientific calculations, including trigonometry, statistics, combinatorics, and numerical integrals; calculate percentages, discounts, sales tax, loans, and compound savings growth; split bills, add up time durations, compare unit prices, work out a GPA, compare dates with working-day counts, resize with an aspect ratio calculator, convert Roman numerals and number words, convert units, explore fuel economy and geometry, and view BMI as a general adult screening measure.
- **Developer tools** — format, flatten, compare, patch, and convert JSON, YAML, TOML, XML, and SQL; generate TypeScript types, Zod schemas, Go, Rust, Python, Java, C#, Kotlin, and Swift models, and JSON Schemas; turn JSON into SQL; encode Base64; convert CSV and JSON; query JSON with JSONPath; validate JSON against a schema; hash local files; generate `.gitignore` templates; inspect `.env` files; explain cron schedules; compare semantic versions; calculate subnets and Unix permissions; check color contrast; generate and inspect UUID, ULID, and NanoID identifiers; generate hashes; test regular expressions; inspect URLs, convert query strings and cURL commands, look up HTTP status codes, convert number bases, escape strings, look up MIME types, review HTTP headers, format JSON Lines, test XPath queries, sign HMACs and generate TOTP codes, convert docker run to Compose, convert CSV/TSV to JSON or SQL, re-indent code, convert HTML to JSX, build CSS gradients, convert .env files, optimise SVG markup, extract JSON from SQL inserts, generate Mongoose/Prisma models, build fluid clamp() sizes, convert Compose services back to docker run, inspect MongoDB ObjectIds, generate C#, Kotlin & Swift models, convert SQL DDL to Prisma/TS/Mongoose, draw Mermaid ER diagrams from JSON, generate seedable JSON fixtures, and verify supported JWT signatures; and work with Unix timestamps.
- **Image & files** — generate QR codes, resize, compress, and crop images, build a full favicon set from one picture, rasterise SVG to PNG, pull the dominant colours out of a photo, read EXIF and image metadata, and check what a file really is from its signature bytes — all locally in your browser.
- **Productivity** — generate strong local passwords, run a focus-and-break timer, or pick fairly from a list.

ClickKit is built around a simple idea: help you finish the task and get on with your day.
